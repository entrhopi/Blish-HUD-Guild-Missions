# Guild Wars 2 Blish HUD Module for Guild Missions

Find waypoint locations and wiki information fast for all guild missions.

Once installed, the module adds a **Guild Missions** tab to the Blish HUD window with a sidebar for each mission type:

- **Treks** — type to search treks, add them to a saved list, then copy all the waypoint chat links to your clipboard at once. Lists can also be exported and imported as short `BlishGM` codes to share with guildmates.
- **Bounties, Races, Challenges, and Puzzles** — browsable lists of mission locations, each with a click-to-copy waypoint chat link and a button that opens the relevant wiki page.

Paste a copied chat link into in-game chat to get a clickable waypoint. The interface is localized in English, German, Spanish, and French.

A **Show corner icon** setting lets you show or hide a Guild Missions icon in the top-left corner of the screen. Clicking the icon opens the Guild Missions tab.

It is recommended to use the Pathing module alongside the marker pack "Lady Elyssa's Guides" or "Tekkit's All-In-One"
